# DS REMOTE DESKTOP — PC IP DISCOVERY & WII IP MANAGEMENT UPDATE

## Summary

? **PC Host Now Displays Its IP Address**
- Auto-detects local network IP (Windows/Linux agnostic)
- Displays prominently on startup with instructions for Wii configuration
- No manual IP entry needed if you read the PC console output

? **Wii Runtime IP Manager**
- SELECT button opens on-screen IP selection menu
- Load saved IPs from sd:/apps/dsremote/ips.cfg
- Switch between PCs without reboot
- Add, remove, manage IPs in-game

? **Persistent Storage**
- IPs saved to SD card (one per line)
- Survives Wii restart
- Template: wii_proxy/ips.cfg

## Usage Flow

### First Time Setup
1. **PC:** Run dsrd_host.exe
   - Console shows: "This PC IP: 192.168.1.100"
2. **Note the IP**
3. **Wii SD Card:** Edit ips.cfg, add that IP
4. **Wii:** Launch app, press SELECT
5. **Wii:** Select IP from list
6. **Wii:** Reconnects automatically

### Runtime IP Switching
1. **PC:** Start another instance on different machine (e.g., 10.0.0.5)
2. **Wii:** Press SELECT during stream
3. **Wii:** Menu appears, select new IP
4. **Wii:** Seamless reconnection, stream continues from new PC
