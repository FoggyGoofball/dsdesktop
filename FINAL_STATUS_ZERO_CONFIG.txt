## User Workflow: First Time

**Hardware:**
1. Wii + SD card (FAT32)
2. PC with dsrd_host running
3. DS with haxxstation or FlashMe

**Setup:**
1. Create sd:/apps/dsremote/
2. Copy wii_proxy/wii_proxy.dol ? sd:/apps/dsremote/boot.dol
3. Copy haxxstation.nds ? sd:/apps/dsremote/ (if using Download Play)
4. Insert SD in Wii

**Operation:**
1. Launch app ? Setup Wizard starts
   - Select USB Ethernet or Wi-Fi
   - Enter PC IP (192.168.1.100, etc.)
   - Choose auto-calibrate or fixed channel
2. Wizard saves configuration to proxy.cfg
3. App starts normally
4. Press SELECT to manage additional IPs
5. Press HOME to exit

---

## User Workflow: Subsequent Boots

**Normal startup:**
1. Insert SD card
2. Launch app from Homebrew Channel
3. ~5 second channel calibration (if enabled)
4. Proxy active
5. Ready to stream

**To switch to different PC:**
1. Press SELECT during operation
2. Select IP from saved list
3. Reconnects automatically
4. Seamless stream continuation
